# Bug Done — Archived bugs

> Bug user verify OK (`[x] Verified`) → **AI auto-move** từ `bug.md` sang đây,
> thêm `Ngày verify`. Giữ nguyên số `BUG #N` — không reuse cho bug mới.
>
> Không sửa content — nếu bug tái diễn, tạo BUG mới trong `bug.md` với số kế tiếp.
>
> File này ban đầu rỗng — bug verified sẽ tự thêm vào theo format:
>
> ```md
> ## BUG #N: <tên bug>
>
> **Status**: `[x] Verified`
> **Ngày tạo**: `<YYYY-MM-DD>`
> **Ngày verify**: `<YYYY-MM-DD>`
> **Severity**: `<Critical / High / Medium / Low>`
>
> ### Triệu chứng (Symptom) / Expected / Root cause / Fix / Verify steps
> ```
