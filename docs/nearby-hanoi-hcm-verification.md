# Nearby data: Ha Noi and Ho Chi Minh City

Date: 2026-09-24

## Data snapshots

| City | Foursquare input | OSM input | Before quality filter | Removed | Current output |
| --- | ---: | ---: | ---: | ---: | ---: |
| Ha Noi | 91 | 7383 | 7462 | 2699 | 4763 |
| Ho Chi Minh City | 95 | 7557 | 7642 | 3164 | 4478 |

Both JSON files were generated by `npm run fetch-places -- ha-noi tp-hcm`.
Every output record has a unique ID, a name, and finite coordinates. The
frontend imports each city file on demand; choosing these cities no longer
falls back to sample data.

The same quality filter removed 1778 of 2977 Da Nang places, leaving 1199.
It permanently removes food, cafe, and shopping records with no address,
phone, or website, as well as names that explicitly say the place is closed.
Tourist and cultural places are retained when they lack those business details.
Future imports also exclude OSM records explicitly tagged inactive or vacant.
Missing details are a quality rule, not proof that a business closed.

## Google Maps spot check

The project has no configured Google Maps API key. A public Maps search was
used for a small spot check; this is **not** a check of every record and does
not establish that every remaining business is still open.

- [Banh Mi 25](https://www.google.com/maps/search/Banh%20Mi%2025) appears at
  25 Hang Ca, Ha Noi, matching the dataset.
- [Banh Mi Huynh Hoa](https://www.google.com/maps/search/L%C3%AA%20Th%E1%BB%8B%20Ri%C3%AAng%2C%20Qu%E1%BA%ADn%201%2C%20S%C3%A0i%20G%C3%B2n)
  appears at 26 Le Thi Rieng, Ho Chi Minh City, matching the dataset.
- [Bep Me In](https://www.google.com/maps/search/restaurants%2BHo%20Chi%20Minh%20City)
  appears at 136/9 Le Thanh Ton, Ho Chi Minh City, matching the dataset.

No records were removed solely because a Google Maps search did not return a
matching listing. Names shared by branches and records without a street
address are especially ambiguous. `needsReview` counts are merge/address
conflicts, not closure findings.

## Application checks

- TypeScript check, merge-engine tests, and production build passed.
- Mobile list and Leaflet map loaded for both new cities and Da Nang.
- Each city rendered 50 initial cards, with no runtime Places/Overpass API
  requests or page errors in the browser check.
- The production build reports large city-data chunks (about 2.5-2.7 MB each
  before gzip after filtering). They load only when a user selects the
  corresponding city.

The first Ho Chi Minh City Overpass request returned HTTP 504. The fetcher now
has a nine-area fallback for this case; a later single-area retry succeeded,
so the fallback path has been type-checked but not exercised end to end.
